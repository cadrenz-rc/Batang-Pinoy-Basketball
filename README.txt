BPBL TOP TABS + LOGO UPDATE

1. On GitHub, open cadrenz-rc/Batang-Pinoy-Basketball/index.html and download the raw index.html file.
2. Extract this ZIP file to a folder.
3. Open apply-update.html in your browser.
4. Select the downloaded original index.html and click Create fixed index.html.
5. Upload these THREE files to your GitHub repository MAIN branch:
   - new index.html (generated by the installer)
   - bpbl-tabs.js (provided in this ZIP)
   - 1000015325.jpg (provided in this ZIP)
6. Commit changes and reload the GitHub Pages website.

The installer keeps all standings, leaderboards, games and filters.
It removes a misplaced JavaScript line from inside <style>.
Tabs will be located immediately below the site header, above the content.
