BPBL 3-TAB WEBSITE UPDATE

1. Open https://github.com/cadrenz-rc/Batang-Pinoy-Basketball/blob/main/index.html
2. Click Download raw file to save the current index.html.
3. Extract this ZIP, open apply-tabs.html in your browser, select the downloaded index.html, and click Create updated index.html.
4. Upload both the NEW index.html and bpbl-tabs.js to the root of your GitHub repository, overwriting only index.html.
5. GitHub Pages should update after deployment.

Tabs: Standings (default), League Leaders (existing division/category/player/team filters), Previous Matchups (existing date/division/team filters). Original data stays unchanged.

Note: This ZIP is an update kit rather than a full static site snapshot because the live source file cannot be copied into the local build environment. Keep your original index.html as a backup.
